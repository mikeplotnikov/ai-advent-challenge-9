# День 31 — ассистент разработчика

Мини-аналог Claude Code для вопросов о проекте: команда `/help` отвечает на вопросы об этом
репозитории по его документации (RAG) и по живому состоянию git (MCP). Ответ пишет DeepSeek
по REST, со ссылками на разделы документации и пометкой `[git]` у фактов из репозитория.

```
вопрос ──► MCP git_branch (всегда, кодом) ──► текущая ветка
       ──► RAG: bge-m3 (Ollama) по README.md + docs/ ──► 5 ближайших фрагментов
       ──► DeepSeek: системный промпт = ветка + фрагменты, инструменты = MCP-сервер
              └─ модель сама вызывает git_status / list_files / git_diff, если вопрос о файлах
       ──► ответ со ссылками [README.md § Раздел] и [git]
```

| Часть | Где |
|---|---|
| RAG по README + `docs/` (чанки по заголовкам, проверка устаревания индекса) | `internal/docrag` |
| MCP-сервер git, только чтение: `git_branch`, `git_status`, `list_files`, `git_diff` | `internal/gitmcp`, `day-31/mcp-server` |
| Описание инструментов (API) | `docs/mcp-tools.md` |
| REPL с командами, цикл «модель ↔ инструменты» | `day-31/main.go`, `internal/toolagent` |

## Запуск

Нужны Ollama с моделью `bge-m3` и ключ DeepSeek в `.env` (`DEEPSEEK_API_KEY_DAY31`
или общий `DEEPSEEK_API_KEY`).

```bash
ollama serve &            # если Ollama ещё не запущена
ollama pull bge-m3

go build -o bin/day31 ./day-31
go build -o bin/day31-mcp ./day-31/mcp-server

./bin/day31 -index        # индекс README.md + docs/ → day-31/index/docs.json (не коммитится)
./bin/day31               # интерактивный режим
./bin/day31 -q "Как устроен проект?"   # один вопрос
```

Команды в интерактивном режиме:

| Команда | Что делает | Модель |
|---|---|---|
| `/help <вопрос>` | ответ о проекте по документации и git | да |
| `/branch` | текущая ветка и последний коммит | нет, прямой вызов MCP |
| `/status` | незакоммиченные изменения | нет |
| `/files [папка]` | файлы проекта, по желанию под префиксом | нет |
| `/diff [путь]` | сводка незакоммиченного diff | нет |
| `/exit` | выход | — |

Флаги: `-repo` — другой репозиторий (по умолчанию корень текущего), `-k` — сколько фрагментов
передавать модели (5), `-ollama` — адрес Ollama, `-server` — путь к бинарнику MCP-сервера.

Если README или `docs/` изменились после `-index`, ассистент при старте называет изменённые
файлы и просит перестроить индекс: ответ не должен молча опираться на старый текст.

## Безопасность

Сервер выполняет только фиксированные read-only команды git; модель передаёт в лучшем случае
префикс пути. Пути с `-`, `:`, `/` в начале и с выходом за корень отклоняются — это проверяет
`internal/gitmcp/server_test.go`. Операций записи (commit, push, удаление) в сервере нет,
поэтому подтверждение пользователя не требуется.
