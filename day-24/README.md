# День 24 — цитаты и источники

Rewrite → bge-m3 → top-10 → cosine ≥ 0.45 → DeepSeek rerank ≥ 2 → top-3 → структурированный ответ с дословными цитатами. Если подходящего контекста нет, код возвращает «Не знаю.» и просьбу уточнить вопрос без генерации ответа.

Из корня репозитория:

```sh
go run ./day-24 -ask 'Что меняет temperature?'
go run ./day-24 -eval
go run ./day-24 -report
go test ./day-24 -count=1
go vet ./day-24
```

Живые команды требуют работающую Ollama bge-m3, индекс дня 21 и ключ через штатные настройки приложения. Ключи не выводятся. -eval выполняет ровно 10 замороженных вопросов дня 22, сохраняет сырые вызовы и фактические usage/cost. Существующий run.json не перезаписывается. -report без сети проверяет хеши, воспроизводит RESULTS.md, showcase.json и этот README.

Независимая оценка в semantic-review.json привязана к SHA256 run.json: `{"run_sha256":"…","questions":[{"id":"…","verdict":"supported|unsupported|unknown","reason":"…"}]}`. Без этого файла строки помечаются pending; цитирование и ограниченная проверка эталонных фактов не выдаются за проверку всего смысла.
