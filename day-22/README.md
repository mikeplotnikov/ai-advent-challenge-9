# День 22. Первый RAG-запрос

Программа сравнивает один и тот же ответ DeepSeek в двух режимах: без базы знаний и с пятью фрагментами, найденными в индексе дня 21.

## Подготовка

1. Запустите Ollama: `ollama serve`.
2. Установите модель эмбеддингов: `ollama pull bge-m3`.
3. Из корня репозитория постройте индекс: `go run ./day-21 -index`.
4. Скопируйте `.env.example` в `.env` и задайте `DEEPSEEK_API_KEY_DAY22` (если переменная пуста, используется общий `DEEPSEEK_API_KEY`).

## Режимы

Живое сравнение двух ответов:

```bash
go run ./day-22 -ask "Насколько блок состояния увеличил объём входа и цену запроса?" -show-prompt
```

Флаг `-mode` принимает `both`, `rag` или `norag`; `-k` задаёт от 1 до 10 чанков и по умолчанию равен 5. Режим `norag` не обращается к Ollama и индексу.

Замороженный прогон из 10 вопросов, двух режимов и трёх повторов:

```bash
go run ./day-22 -eval
```

Он один раз создаёт `run.json`, `RESULTS.md` и `showcase.json`. Существующий `run.json` не перезаписывается. Отчёт из уже сохранённого сырья пересобирается без вызовов модели и Ollama:

```bash
go run ./day-22 -report
```

## Промпт

Оба режима получают одинаковый system-промпт. Без RAG user-сообщение содержит только вопрос. С RAG перед вопросом идут найденные чанки в порядке ранга и требование отвечать только по ним, указывая источник после каждого утверждения. Если данных нет, модель должна вернуть `[[НЕТ ДАННЫХ]]`.

## Как считается качество

Факты ищутся регулярными выражениями из замороженного `eval/questions.json`, а незнание — по буквальному маркеру. Для вопросов из базы и общего вопроса успехом считается `correct`; для вопросов вне базы — `declined`. В каждом режиме вопрос успешен по большинству двух из трёх повторов. Отдельно считаются попадание эталонной цитаты и ожидаемого файла в top-5, корректность ссылок ответа, исходы, токены, цена и время. Единственная заранее объявленная проверка различия — двусторонний точный тест Макнемара при α = 0,05.

Таблицы из `RESULTS.md` будут вставлены сюда дословно после единственного живого прогона. До него числовых результатов нет.
