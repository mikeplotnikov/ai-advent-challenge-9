# День 17 — свой MCP-сервер и агент, который его вызывает

Задание дня 17 AI Advent Challenge #9: «Реализуйте свой MCP-сервер вокруг любого API …
регистрацию инструмента, описание входных параметров, возврат результата. Подключите инструмент
к своему агенту и: вызовите его из приложения, получите и используйте результат».

Ведущий в чате: «Агент обработает результат и он же вызовет тул из схемы». Здесь так и сделано:
модель сама выбирает инструмент по схеме, агент его вызывает и возвращает результат модели.

- **Сервер** `day-17/mcp-server` — отдельная программа на официальном
  [go-sdk](https://github.com/modelcontextprotocol/go-sdk) v1.8.0 вокруг API курсов ЦБ РФ
  (`https://www.cbr.ru/scripts/XML_daily.asp`). Два инструмента: `get_currency_rates` (курсы на
  дату) и `convert_currency` (пересчёт суммы). Схемы параметров сервер выводит из Go-структур
  (`internal/ratesmcp`), логика ЦБ — в `internal/cbr`. Транспорт — stdio или Streamable HTTP.
- **Агент** `day-17` поверх `internal/toolagent`: `tools/list` → схемы один к одному уходят в
  DeepSeek как `tools` → модель отвечает `tool_calls` → агент делает MCP `tools/call` → результат
  уходит модели сообщением `role: "tool"` → текстовый ответ. Не больше 5 обращений к модели на
  вопрос. Своих схем у агента нет.
- **Тот же сервер на удалённой машине**: витрина `https://challeng.mikeproject.dev/day-17/`,
  публичный MCP-эндпоинт `POST https://challeng.mikeproject.dev/api/day17-mcp`. Это JS-двойник
  Go-сервера; совпадение проверяется машинно на эталонных случаях из `go run ./day-17 -dump`.

## Запуск

Из корня репозитория, ключ DeepSeek — в `.env` (`DEEPSEEK_API_KEY_DAY17` или `DEEPSEEK_API_KEY`):

```bash
go run ./day-17 "Сколько рублей стоили 250 долларов США 1 сентября 2026 года по курсу ЦБ?"
go run ./day-17 -endpoint https://challeng.mikeproject.dev/api/day17-mcp "Курс юаня на 1 сентября 2026"
go run ./day-17 -no-tools "Сколько рублей стоили 250 долларов США 1 сентября 2026 года по курсу ЦБ?"
go run ./day-17 -save trace.json "Курс евро на 20 сентября 2026"
go run ./day-17/mcp-server                     # сервер по stdio
go run ./day-17/mcp-server -http 127.0.0.1:8080 # сервер по HTTP, путь /mcp
go run ./day-17 -dump                          # определения и эталоны для сверки с витриной
go run ./day-17 -bench                         # замер, пишет bench.json и RESULTS.md
./day-17/demo.sh                               # сценарий скринкаста
```

`-endpoint` нельзя сочетать с явным `-command`. `-no-tools` — контроль: MCP не поднимается, в
запросе нет `tools`. `-save` пишет трассу без ключа. Коды выхода: 0 — ответ получен, 1 — ошибка
MCP, DeepSeek, лимита шагов или записи `-save`, 2 — ошибка использования.

## Замер: как надёжно модель зовёт инструмент и использует результат

`convert_currency`, **N** — инструмент не нужен. Контроль — вопросы R и C без инструментов.

**Что это значит.** На этом наборе `deepseek-flash` при `temperature 0` вызывал нужный
инструмент с верными аргументами и использовал результат во всех 60 прогонах R и C. Ни разу не
позвал инструмент там, где он не нужен (N). Каждый вопрос R/C стоил ровно 2 обращения к модели.
Интервалы Уилсона — вот честная точность: 30 из 30 даёт нижнюю границу 88,6%, не «100% всегда».

**Контроль показывает, что проверка различает.** Без инструментов числа из ЦБ нет ни в одном из
20 ответов. Как модель ведёт себя без инструментов (пересчитывается из `bench.json`):

```bash
jq '[.runs[] | select(.arm=="no-tools") | .trace.finalAnswer | select(test("\"tool\"\\s*:|<tool_call>|^\\s*\\{"))] | length' day-17/bench.json  # 17 из 20
jq '[.runs[] | select(.arm=="no-tools") | .trace.finalAnswer | select(test("будущ"))] | length' day-17/bench.json                        # 2 из 20
```

В 17 ответах из 20 модель печатает текстом псевдовызов инструмента, например
`{"tool":"currency_conversion","arguments":{"amount":250,"from":"USD","to":"RUB","date":"2026-09-01"}}`:
системный промпт велит брать курсы из инструментов, а инструментов нет. В 2 ответах прошедшая
дата названа «будущей». Один раз модель выдумала курс: «1 EUR = 92,5000 ₽ … ≈ 54,05», хотя по
данным ЦБ 5000 ₽ на 03.08.2026 — это 54,8291 € (курс от 01.08.2026). Это и есть разница между
«модель знает» и «модель получила из инструмента».

## Как проверяется

- `go test -count=1 ./...` — сервер (правила дат, cp1251, номиналы, ошибки ЦБ как `isError`,
  кэш), агент (цикл на фейковом DeepSeek и настоящем сервере по in-memory транспорту, отказ по
  неизвестному инструменту и битому JSON без обращения к MCP, лимит 5 шагов), CLI (коды выхода,
  stdio-подпроцесс и HTTP с фейковым ЦБ, `-save` без ключа), замер (разбор чисел, контроль).
- `internal/llm`: запрос без инструментов побайтно тот же, что до добавления tool calling.
- Витрина: `challeng/test/day17-{parity,endpoint,page}.mjs` в репозитории `uchebnik-ai-advent`.

## Ограничения

- Источник курсов — только официальный XML ЦБ РФ. Даты — от 1998-01-01 (деноминация) до
  завтрашнего дня по Москве; на выходной и праздник возвращается действующий курс с пояснением
  в поле `note`.
- cbr.ru отвечает `403` на User-Agent `Go-http-client/1.1`, поэтому клиент называет себя явно.
- Замер — одна модель, одна температура, 10 вопросов на группу: это надёжность на этом наборе,
  а не свойство модели вообще.
- Команда stdio по умолчанию `go run ./day-17/mcp-server` требует запуска из корня репозитория.
