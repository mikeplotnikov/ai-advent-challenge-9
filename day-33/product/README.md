# Парта — онлайн-школа

Парта — вымышленная онлайн-школа для демонстрации ассистента поддержки (день 33 челленджа).
Ученики проходят видеокурсы в браузере и в мобильном приложении, сдают домашние задания и
получают сертификаты.

## Тарифы

- **Старт** — бесплатно: первые 3 урока каждого курса.
- **Про** — 990 ₽ в месяц: все курсы, домашние задания с проверкой, сертификаты.
- **Команда** — 790 ₽ в месяц за ученика, от 5 учеников: всё из «Про» плюс отчёты для руководителя.

## Поддержка

Поддержка отвечает в чате на сайте. Первая линия — AI-ассистент; если вопрос требует решения
человека (возврат вне правил, ручная разблокировка, сбой оплаты на стороне банка), ассистент
передаёт тикет специалисту. Специалист отвечает в рабочие дни с 10:00 до 19:00 по Москве.
