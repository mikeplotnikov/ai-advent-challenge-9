# День 28 — локальная LLM + RAG

Весь рабочий маршрут — в браузере: вопрос, локальный embedding bge-m3, cosine-поиск по индексу недели 5, до трёх фрагментов, Qwen3:4b, ответ и проверяемые цитаты. В конвейере нет облачного rewrite/rerank или fallback. Индекс загружается один раз.

Перед записью, из корня репозитория:

```sh
# Модели уже установлены на Mac владельца. На другом Mac:
ollama pull bge-m3
ollama pull qwen3:4b
# Если daemon не запущен, в отдельном окне:
ollama serve
# Индекс восстанавливается из прежнего корпуса, если его нет:
go run ./day-21 -index
# Живое приложение:
go run ./day-28
```

Открыть http://127.0.0.1:8028/?record=1. Во время записи терминал не нужен. В браузере можно ввести произвольный вопрос, раскрыть найденные документы, дождаться ответа, отменить запрос или сбросить интерфейс.

Публичная интерактивная копия: https://challeng.mikeproject.dev/day-28/?record=1. Она показывает сохранённые настоящие прогоны, не обращается к Mac и не генерирует новые ответы. Режим явно подписан.

## Проверки и измерения

```sh
go test ./day-28 -count=1
go test -race ./day-28 -count=1
go vet ./day-28
python3 -m unittest discover -s day-28 -p '*_test.py'
python3 day-28/report.py --check
# Новый файл, существующие данные не перезаписываются:
go run ./day-28 -eval-out /tmp/day28-new-run.json
```

Измерения: все десять вопросов дня 22, три повторения с замороженными параметрами. Исходные запросы/ответы и неуспешные попытки сохранены в run.json. format использует JSON schema: модель выбирает источник и дословную цитату из буквальных строк/абзацев найденных документов. Это ограничивает копирование цитат; содержание ответа отдельно проверяется по эталонам и смысловой оценке. Валидная цитата не гарантирует верный ответ.

Одна дополнительная попытка допускается только при ошибке контракта ответа; обрыв, HTTP-сбой или отсутствие модели не превращаются в «не знаю». Пустой контекст вызывает локальный отказ без генерации. Сервер слушает только loopback; запросы приложения к Ollama ограничены loopback; proxy и redirects отключены, remote/cloud metadata отклоняются. Полная изоляция сетевого трафика daemon не проверялась.

Для сравнения генерации Qwen получает точные сохранённые сообщения восьми запросов DeepSeek дня 24 от 01.10.2026. Входы одинаковые, но параметры backend и среды различаются. Этот эксперимент не сравнивает полный новый retrieval с прежним облачным rewrite/rerank. Облачные ответы архивные, их повторяемость не измерялась. Ключи API этому приложению не нужны. В архивном сравнении приняты 7 из 8 Qwen-ответов: один после двух попыток нарушил контракт отказа. Его исходные ответы сохранены, ошибка явно показана; она не входит в 30 основных локальных прогонов.

Метрики и смысловые вердикты: RESULTS.md, showcase.json, semantic-review.json. report.py проверяет происхождение, исходные ответы, цитаты и пересчитывает числа. Неверные ответы не исправляются вручную.
