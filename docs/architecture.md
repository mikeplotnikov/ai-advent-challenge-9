# Архитектура репозитория

Репозиторий — решения заданий челленджа AI Advent Challenge #9: один Go-модуль
`github.com/mikeplotnikov/ai-advent-challenge-9` (Go 1.27, `go.mod` в корне), одна папка
на задание (`day-NN/`) и общие пакеты в `internal/`. Единственная внешняя зависимость
первого уровня — официальный MCP SDK `github.com/modelcontextprotocol/go-sdk` v1.8.0.

## Слои

| Слой | Где | Что делает |
|---|---|---|
| Задания | `day-01/` … `day-32/`, плюс `day-01-web/` (веб-вариант дня 1) | `main.go` дня — CLI или веб-сервер (кроме `day-07`–`day-09`); с `day-09` рядом `README.md`, часто `RESULTS.md` с замером |
| Общие пакеты | `internal/` | код, который переиспользуют несколько дней |
| Секреты | `.env` (в `.gitignore`) | ключи DeepSeek; шаблон — `.env.example` |
| CI | `.github/workflows/day-18-agent.yml`, `.github/workflows/day-32-review.yml` | агент дня 18 по расписанию; AI-ревью каждого PR (день 32, self-hosted runner на Mac владельца, включается `day-32/runner.sh`) |

## Пакеты `internal/`

| Пакет | Назначение |
|---|---|
| `internal/llm` | общий клиент DeepSeek по REST: запрос, ответ, вызовы инструментов, прайс-лист и расчёт цены (`CostAt`) |
| `internal/stats` | интервалы Уилсона, точный тест Фишера, bootstrap — арифметика выводов из замеров |
| `internal/agent` | агент недель 2–3: стек сообщений, память, профиль, состояние задачи, инварианты |
| `internal/mcpclient` | MCP-клиент: транспорт stdio или Streamable HTTP, `tools/list`, сессия с `tools/call` |
| `internal/toolagent` | цикл «модель ↔ инструменты»: отдаёт модели схемы MCP-инструментов и исполняет её вызовы |
| `internal/cbr` | загрузка и нормализация курсов ЦБ РФ |
| `internal/ratesmcp` | MCP-сервер курсов ЦБ (день 17) |
| `internal/watch`, `internal/watchmcp` | наблюдения за курсами по расписанию и их MCP-сервер (день 18) |
| `internal/pipelinemcp` | MCP-сервер композиции инструментов (день 19) |
| `internal/clockmcp` | MCP-сервер календаря по Москве (день 20) |
| `internal/mcprouter` | реестр нескольких stdio MCP-серверов и маршрутизация инструментов по пространствам имён (день 20) |
| `internal/rag` | часть RAG дня 21, нужная во время запроса: эмбеддинги через Ollama, ранжирование чанков по косинусу |
| `internal/docrag` | RAG по документации проекта (README + `docs/`): чанкинг по заголовкам, индекс, проверка устаревания (день 31) |
| `internal/gitmcp` | MCP-сервер с фактами git о репозитории, только чтение (день 31) |

- `day-18` — планировщик и фоновые задачи: агент, который работает 24/7
- `day-19` — композиция MCP-инструментов
- `day-20` — оркестрация нескольких MCP-серверов
- `day-21` — индексация документов
- `day-22` — первый RAG-запрос
- `day-23` — реранкинг и фильтрация
- `day-24` — цитаты и источники
- `day-25` — мини-чат с RAG и памятью задачи
- `day-26` — запуск локальной LLM
- `day-27` — локальная LLM в веб-приложении
- `day-28` — локальная LLM + RAG

## Модели

- Облачная модель по умолчанию — `deepseek-v4-flash` (`internal/llm`, константа `DefaultModel`),
  эндпоинт `https://api.deepseek.com/chat/completions`. Модель меняется переменной `DEEPSEEK_MODEL`.
- Локальные модели (дни 5, 26–30) и эмбеддинги RAG (`bge-m3`, дни 21–25, 28, 29 и 31) — через Ollama
  на `http://127.0.0.1:11434`.
