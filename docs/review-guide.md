# Правила ревью PR

Что проверяет ревьюер — человек или AI-ревью дня 32 — в любом pull request этого репозитория.
Структура, ключи и тесты повторяют `docs/conventions.md` и `docs/architecture.md`; разделы про ошибки,
ресурсы и модель — правила для нового кода, принятые вместе с днём 32.

## Структура изменения

- Новое задание — папка `day-NN/` с `main.go` (`package main`) и `README.md`; строка в таблице
  `docs/architecture.md`.
- Код, который нужен второму дню, переезжает в `internal/<пакет>`, а не копируется. Дублирование
  того, что уже есть в `internal/` (клиент модели, MCP-клиент, RAG, статистика), — архитектурная проблема.
- `internal/` не импортирует пакеты `day-NN`: зависимость идёт только от дня к общему коду.
- Вспомогательные программы дня — в подпапках дня (например `day-31/mcp-server/`).

## Ключи и секреты

- Ключ DeepSeek читается через `llm.NewWithKeyEnv("DEEPSEEK_API_KEY_DAYNN")`; новая переменная
  добавляется в `.env.example` пустой.
- Значения ключей, токенов и паролей не попадают в код, тесты, логи и вывод программы.
- Сгенерированное локально — индексы, состояние, отчёты, кэши — в `.gitignore`, не в коммите.

## Ошибки и ресурсы

- Ошибка не проглатывается: возвращается вызывающему с контекстом (`fmt.Errorf("…: %w", err)`)
  или обрабатывается там, где программа может восстановиться. `_ = f()` у функции, возвращающей
  ошибку, требует объяснения.
- Открытый файл, тело HTTP-ответа, дочерний процесс закрываются (`defer …Close()`) на всех путях,
  включая ранний `return` с ошибкой.
- Ответ внешнего API проверяется по телу, а не только по коду статуса.

## Модель и цена

- Цена вызова считается только через `llm.CostAt` с моментом вызова: тарифы DeepSeek зависят от часа
  и от кэша.
- Формат ответа модели задаётся полем запроса (`ResponseFormat: "json_object"`) и проверяется
  кодом: валидный JSON ещё не значит нужную схему.
- Текст из модели или из внешних источников, который печатается в терминал, проходит через
  `rag.TerminalSafe` / `rag.TerminalSafeMultiline`.

## Тесты

- Изменение наблюдаемого поведения сопровождается тестом.
- Тесты не платят за вызовы: модель подменяется интерфейсом или переменной `DEEPSEEK_API_URL`,
  Ollama и GitHub — локальным `httptest`-сервером.
- Перед PR: `go build ./...`, `go vet ./...`, `go test ./...` зелёные.
