# День 17 — MCP-агент курсов ЦБ

> «Агент обработает результат и он же вызовет тул из схемы».

Здесь есть собственный MCP-сервер официальных курсов ЦБ РФ и агент на Go. Агент получает
`tools/list`, без ручных схем передаёт их DeepSeek, исполняет выбранные моделью вызовы и возвращает
результат в диалог. Это показывает не знание модели о курсах, а использование результата инструмента.

Запускать из корня репозитория:

```bash
go run ./day-17 "Сколько рублей стоили 250 долларов США по курсу ЦБ на 1 сентября 2026?"
go run ./day-17/mcp-server
go run ./day-17/mcp-server -http 127.0.0.1:8080
go run ./day-17 -endpoint https://challeng.mikeproject.dev/api/day17-mcp "Курс доллара на 1 сентября 2026"
go run ./day-17 -no-tools "Что такое ISO 4217?"
go run ./day-17 -save trace.json "Курс юаня на 1 сентября 2026"
go run ./day-17 -timeout 30s -command "go run ./day-17/mcp-server" "Курс евро на 1 сентября 2026"
go run ./day-17 -dump
go run ./day-17 -bench
```

`-endpoint` выбирает Streamable HTTP вместо stdio; его нельзя сочетать с явно переданным
`-command`. `-no-tools` не запускает MCP-сервер и не передаёт модели `tools`. `-save` сохраняет
JSON-трассу без ключа. Таймаут одного вопроса задаётся `-timeout` (по умолчанию `90s`).

`-bench` создаёт `bench.json` и `RESULTS.md` только в живом прогоне владельца: он делает платные
запросы к модели. Числа в `RESULTS.md` появятся после такого прогона; они не подставляются заранее.

## Пример трассы — вставляется после живого прогона

В трассе видны сервер, `tools/list`, каждый шаг модели, `tools/call` и финальный ответ. Тексты
инструмента перед печатью очищаются от управляющих символов.

## Ограничения

Источник курсов — только XML ЦБ РФ. Даты допустимы от 1998-01-01 до завтрашнего дня по UTC+3;
выходной может вернуть курс предыдущего рабочего дня с пояснением. Команда stdio по умолчанию
`go run ./day-17/mcp-server` поэтому требует запуск из корня репозитория.
